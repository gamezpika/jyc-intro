六、風險與注意事項

1. LINE 費用隨量暴增
住戶超過 5,000 人且公告頻繁時，每月推播可能衝到 50,000 則，LINE 費用升至 NT$9,000+。
對策：公告改「LIFF 網頁閱讀 + 一則推播提醒」，可壓低 80% 廣播量。
2. Gemini 免費額度可能取消
目前部分 API Key 用免費 tier，正式商用建議全部轉付費 tier。
影響：AI 費用從 NT$800 升至 ~NT$2,500/月，對利潤影響極低（<1%）。
3. 多社區資料隔離
目前系統沒有 community_id 隔離，33 案場上線前需開發資料隔離功能。
額外開發成本：~40-60hr（一次性）。
4. LINE 帳號策略
33 案場共用一個 LINE 帳號：訊息費省但管理混亂。每案場獨立帳號：月費 ×33。
建議：先共用降低成本，後續按客戶需求拆分，拆分成本由客戶承擔。
