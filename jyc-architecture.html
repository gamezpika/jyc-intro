Use Cases

三入口協作情境

同一件事，不同角色各用自己最熟悉的工具完成。流程中有「前往後台」按鈕直接跳轉。

01

🚗 住戶預約訪客（私人 / 商業）

📱 住戶 · LINE
1. 填訪客資訊

Rich Menu 點「訪客預約」→ 填訪客姓名、時段、車位（系統自動配空格）→ 送出

→
🖥️ 管理處 · Web
2. 商業訪客核發

商業訪客需確認收款 → 後台按「核發 QR」；私人訪客系統自動發送

前往訪客預約 →
→
📱 住戶 · LINE
3. 收到 QR

LINE 推播 QR 通行碼 → 一鍵分享給訪客（Flex Message 格式）

→
🖥️ 保全 · Web
4. 掃碼放行

手機相機掃 QR 自動開掃碼頁 → 確認放行 → 住戶 LINE 即時收到「訪客已到場」

掃碼放行頁 →
02

🔧 住戶報修流程

📱 住戶 · LINE
1. 提交報修

報修頁填問題描述 + 附上照片（AI 自動判讀異常類型）

→
🤖 主管 · TG
2. 收到通知並指派

TG 推播新工單 → 指派給負責員工（保全 / 清潔 / 工務）

→
🖥️ 員工 · 後台
3. 處理並回報

員工 TG 或後台看工單 → 現場處理 → 拍照回報 → 完結工單

工單管理 →
→
📱 住戶 · LINE
4. 收到完成通知

LINE 推播「已修復」+ 服務評分連結（可匿名留意見）

03

📝 員工請假全流程

🤖 員工 · TG
1. 送出申請

TG 開 Mini App 表單 → 選假別與期間 → 系統自動檢查額度 → 送出

→
🤖 主管 · TG
2. 一鍵審批

TG 推播申請通知 → 按鈕「✅ 核准 / ❌ 駁回」一按結束

→
🤖 員工 · TG
3. 收到結果

TG 推播審批結果；核准自動扣請假額度

→
🖥️ 人資 · Web
4. 完整紀錄

Web 後台查閱所有請假紀錄、CSV 匯出、月報出勤表一次到位

請假管理 →
04

📢 社區公告發布

🖥️ 秘書 · Web
1. 建立公告

富文本編輯（粗體 / 顏色 / 連結 / 插圖）+ 附件上傳

新增公告 →
→
🖥️ 秘書 · Web
2. 排程發布

設定發布時間、過期時間、置頂、歸屬社區（多案場隔離）

公告管理 →
→
📱 住戶 · LINE
3. 收到通知

LINE 推播摘要 → 點進看完整公告（含圖文與附件）

→
📱 住戶 · LINE
4. 持續曝光

重要公告置頂展示；行事曆同步呈現；過期自動隱藏
