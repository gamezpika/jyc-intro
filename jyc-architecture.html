一套系統
貫穿物業公司、案場、住戶

JYC 怡盛物業智慧管理系統由三層架構組成、搭配三個專精入口：Telegram 給員工、LINE 給住戶、Web 後台給管理者。

Three-Layer Architecture

三層一體 · 由上而下

物業公司統籌員工 → 案場獨立營運 → 住戶自助服務

🏢
LAYER 1 · 物業公司

JYC 怡盛物業

系統最高層，統籌所有員工與跨案場調度。員工透過 staff_profiles.community_id 分派到某個案場服務。

員工管理 跨案場調度 決策看板 人事 / 薪資 對內行事曆 角色權限
↓
🏘️
LAYER 2 · 案場 / 社區

Community（目前 9 個真實社區）

每個案場是獨立營運單位，有自己的門牌、車位、公設、公告、帳單。左上角切換器切案場，cookie wb_active_community 自動過濾所有對外服務頁資料。

🚪 門牌 Household 🅿️ 車位 Parking 🏊 公設 Amenity 📢 公告 Announcement 💰 帳單 Bill 🔧 工單 Repair 📦 包裹 Package ⭐ 評分 Rating 📅 對外行事曆
↓
👥
LAYER 3 · 住戶

Household + Resident

門牌（一戶）底下有多位成員。成員可綁 LINE 個人帳號，綁定後開通所有 LIFF 服務，並可用匿名評分、議案投票、訪客預約等功能。

🚪 一戶 = 一門牌 👤 多位成員 🔗 綁 LINE 個人帳號 📱 LIFF 自助服務 🔒 匿名評分（sha256）
Three Portals

三個入口 · 各自專精

對的人用對的工具 — 員工用 TG、住戶用 LINE、管理用 Web

🤖
員工端

Telegram Bot

@wobot_JYC_bot

常用指令

  • /in 上班打卡（需傳位置）
  • /out 下班打卡
  • /clock 打卡紀錄
  • /leave 請假申請
  • /overtime 加班申請
  • /makeup 補打卡
  • /balance 查詢假別額度
  • /shift 查我的班表
  • /menu 完整功能選單

特色

所有表單走 TG Mini App（原生體驗）。主管端收到申請 → Inline 按鈕一鍵核准 / 駁回 → 員工即時收到推播。

定位打卡含地理圍欄：超出半徑直接擋下，不進 DB。

適用角色

社區經理、秘書、財務、保全、清潔 — 全體案場人員。

📋 我的紀錄

Tab 2 · 社區互動

⭐ 服務評分
📢 社區公告
📞 聯絡客服
🗳️ 議案投票
✉️ 意見箱
🏠 我的戶籍

特色

訪客預約自動產生 QR → 住戶一鍵分享給訪客 → 保全掃碼放行後住戶即時收到到場推播。評分匿名（sha256 hash 24h 防刷）。

🖥️
管理端

Web 後台

web-production-ea976.up.railway.app

模組分類（三大群組）

🏠 對外服務

社區結構 · 戶與成員 · 訪客預約 · 車位池 · 工單報修 · 社區公告 · 公設預約 · 帳單繳費 · 供應商管理

👥 對內管理

員工帳號 · 人事（排班 / 考勤 / 請假 / 加班 / 補卡 / 薪資公式 / 勞健保）· 決策（招募 / 看板 / 統計 / 住戶評分融入）

⚙️ 系統

角色權限

  • admin 全域系統管理員
  • maintainer 維護者，可改設定
  • member 員工，只看自己

特色

左上社區切換器一按即切整套資料（cookie 驅動）；完整稽核軌跡；CSV 匯出；Quill 富文本公告；多附件上傳。

Use Cases

三入口協作情境

同一件事，不同角色各用自己最熟悉的工具完成

01

🚗 住戶預約訪客（私人 / 商業）

📱 住戶 · LINE
1. 填訪客資訊

Rich Menu 點「訪客預約」→ 填訪客姓名、時段、車位（自動配空格）→ 送出

→
🖥️ 管理處 · Web
2. 商業訪客核發

商業訪客需確認收款 → 後台按「核發 QR」；私人訪客自動發 QR

→
📱 住戶 · LINE
3. 收到 QR

LINE 推播 QR → shareTargetPicker 一鍵分享 Flex Message 給訪客

→
🖥️ 保全 · Web
4. 掃碼放行

iOS 相機掃 QR 自動開掃碼頁 → 放行 → 住戶 LINE 收「訪客已到場」

02

🔧 住戶報修流程

📱 住戶 · LINE
1. 提交報修

報修頁填問題描述 + 附上照片（AI 自動分析異常）

→
🤖 主管 · TG
2. 收到通知並指派

TG 推播新工單 → 轉指派給負責員工（保全 / 清潔 / 工務）

→
🤖 員工 · TG
3. 處理並回報

員工 TG 收到工單 → 現場處理 → 拍照回報 → 完結工單

→
📱 住戶 · LINE
4. 收到完成通知

LINE 收「已修復」+ 服務評分連結（匿名評分）

03

📝 員工請假全流程

🤖 員工 · TG
1. 送出申請

/leave → Mini App → 填假別 / 期間 → 系統先檢額度 → 送出

→
🤖 主管 · TG
2. 一鍵審批

TG 推播 → Inline 按鈕「✅ 核准 / ❌ 駁回」一按結束

→
🤖 員工 · TG
3. 收到結果

TG 推播審批結果；核准自動扣額度

→
🖥️ 人資 · Web
4. 完整紀錄

Web 後台查所有請假紀錄 · CSV 匯出 · 月報出勤表

04

📢 社區公告發布

🖥️ 秘書 · Web
1. 建立公告

Quill 富文本編輯（粗體 / 顏色 / 連結 / 圖片）+ 附件上傳（每檔 10MB）

→
🖥️ 秘書 · Web
2. 排程發布

設定發布 / 過期時間、置頂、歸屬社區（多案場隔離）

→
📱 住戶 · LINE
3. 收到通知

LINE 推播摘要 → 點進 LIFF 公告頁看 HTML 渲染 + 附件下載

→
📱 住戶 · LINE
4. 置頂持續曝光

重要公告置頂 · 行事曆同步顯示 · 過期自動隱藏

Data Model

資料關聯（簡化 ER）

三層怎麼在 DB 中用 Foreign Key 串起

🏢 物業公司
（系統隱含層）
無獨立 table，JYC 本體
🏘️ 案場
communities
id · name · 座標 · 地政資料
🚪 門牌
households
community_id → building · unit
👤 住戶成員
residents
household_id · line_user_id
關鍵關聯：
· staff_profiles.community_id → 員工被分派到哪個案場
· households.community_id → 戶屬於哪個案場
· residents.household_id → 成員屬於哪一戶
· residents.line_user_id → 綁定到 LINE 個人帳號
· parking_slots / amenities / announcements / bills 全部都有 community_id → 多案場資料隔離
