01

🚗 住戶預約訪客（私人 / 商業）

📱 住戶 · LINE
1. 填訪客資訊

Rich Menu 點「訪客預約」→ 填訪客姓名、時段、車位（系統自動配空格）→ 送出

→
🖥️ 管理處 · Web
2. 商業訪客核發

商業訪客需確認收款 → 後台按「核發 QR」；私人訪客系統自動發送

前往訪客預約 →
→
📱 住戶 · LINE
3. 收到 QR

LINE 推播 QR 通行碼 → 一鍵分享給訪客（Flex Message 格式）

→
🖥️ 保全 · Web
4. 掃碼放行

手機相機掃 QR 自動開掃碼頁 → 確認放行 → 住戶 LINE 即時收到「訪客已到場」

掃碼放行頁 →

🔧 住戶報修流程

📱 住戶 · LINE

→

→

工單管理 →
→

4. 收到完成通知

03

📝 員工請假全流程

🤖 員工 · TG
1. 送出申請

TG 開 Mini App 表單 → 選假別與期間 → 系統自動檢查額度 → 送出

→

2. 一鍵審批

TG 推播申請通知 → 按鈕「✅ 核准 / ❌ 駁回」一按結束

→
🤖 員工 · TG
3. 收到結果

TG 推播審批結果；核准自動扣請假額度

→
🖥️ 人資 · Web
4. 完整紀錄

Web 後台查閱所有請假紀錄、CSV 匯出、月報出勤表一次到位

→
