📅 班表查詢 + 排班需求

員工 TG 提需求 × 主管 Web 排班
PART 1 · 員工 TG

查班表 + 提排班需求

員工開 Mini App 看本月已排班，並送出排班需求（休假需求、班別偏好）給主管。

PART 2 · ✨ AI 亮點 · AI 自動排班 ↗ 對應「Tab 2 排班引擎」

月排班 AI 一鍵出班 + 補缺微調

主管不用手動排，AI 一鍵生成整月班表，再用補缺微調自動補齊空缺，並標出違規格 — 主管只要做最後確認，整月排班從整週縮成幾分鐘。

💼 業務操作

🔧 工單與 AI 影像輔助

部分已有影片 空拍巡檢 + 清潔智慧回報（開發中）
✨ AI 亮點 · 🚁 空拍機巡檢（開發中） ↗ 對應「Tab 4 安全守護」

AI 影像辨識可疑人物

空拍機拍一張照片回傳 AI，即可初步判斷可疑人物是否需要派人前往。社區大範圍巡檢從靠人變靠 AI。

✨ AI 亮點 · 🧽 清潔智慧回報（開發中） ↗ 對應「Tab 3 視覺辨識」

AI 自動判斷清潔狀態

清潔人員隨手拍一張照片回傳，AI 自動判斷環境是否需要清潔、是否有異常，零負擔留存紀錄。

✨ AI 亮點 · 🤖 任務萃取 ↗ 對應「Tab 1 群組 AI 中樞」

群組對話 → AI 自動建工單

員工在 TG 群組裡用自然語言講「漏水了」「電梯卡住」「住戶反映 XX」，AI 直接從對話內容萃取出標準化工單，不用切換系統、不用填表單。流程零摩擦：講一句話 → AI 建工單 → 派工 → 處理 → 回報，整段不離開 Telegram。

住戶 LINE 預約 × 管理處 Web 管控
PART 1 · 住戶 LINE

線上預約公設

Rich Menu 點公設 → 選類別（健身房 / 交誼廳 / KTV）→ 看可用時段 → 確認預約。

PART 2 · 管理處 Web

後台管控預約

後台看所有預約紀錄 → 管理檔期 / 取消 / 統計使用率，避免衝突與重複預約。

💰 繳費查詢與管理

開立 → LINE 通知 → 線上繳費 → 後台核對
PART 1 · 管理處 Web

開立帳單

後台選項目、金額、期間 → 建立應收帳單 → 系統自動 LINE 推播給住戶。

PART 2 · 住戶 LINE

收推播 + 看明細

住戶收到 LINE 推播 → LIFF 看當期應繳金額、項目、繳款期限。

PART 3 · 管理處 Web

後台檢視繳費憑證

管理者後台一眼看到住戶上傳的繳費憑證、轉帳截圖等，不用一個個對帳問候，效率大幅提升。

PART 4 · 住戶 LINE

狀態即時更新

管理處核對收款後，住戶 LINE 端即時看到「已繳費」狀態，不用打電話問櫃台確認。

📋 我的紀錄

個人 dashboard 整合所有服務
住戶端 · LINE LIFF

一頁看完個人所有事項

頂部四格摘要：未繳金額、包裹待領、報修處理中、訪客預約，數字一目了然。下方依序展開帳單明細（可看全部）、訪客預約歷史、報修紀錄，住戶不用切換多個畫面就能掌握自己跟社區的所有往來。
